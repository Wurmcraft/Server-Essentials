# Logging Module

The Logging module is designed to log events and be able to roll them back.

Name: `Logging`

Requirements: `Core`

Note: This module does not currently do anything.

### Commands

| Name | Permission Node | Description | Default Aliases | Recommended Security |
|------|-----------------|-------------|-----------------|----------------------|

### Config

File: `Modules/Logging.json`

| Name              | Description                    |
|-------------------|--------------------------------|
| `loggingLocation` | Where to save the logging data |
| `database`        | Database login info            |
| `logging`         | Events that you want to log    |

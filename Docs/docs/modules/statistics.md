# Statistics Module

The Statistics module is a module designed to track stuff, like block breaks, when players are online, teleports and
just other statical data for server staff

Name: `Statistics`

Requirements: `Core`

Note: This module does not currently do anything.

### Commands

| Name | Permission Node | Description | Default Aliases | Recommended Security |
|------|-----------------|-------------|-----------------|----------------------|

### Config

File: `Modules/Statistics.json`

| Name            | Description                      |
|-----------------|----------------------------------|
| `deaths`        | Track player deaths              |
| `countCommands` | Track when commands are run.     |
| `blockBroken`   | How many blocks are broken       |
| `blocksPlaced`  | How many blocks are placed       |
| `entityKills`   | How many entities are killed     |
| `groundItems`   | How many items are on the ground |
